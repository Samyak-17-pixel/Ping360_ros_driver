Ping360 Viewer
Same-machine: use 127.0.0.1 (SSH optional). Remote: Jetson SSH credentials.
Tip: you’ll browse to http://<jetson-ip>:8080 when connected to WiFi. Rosbridge is opened by the machine running Ping360 Viewer (not only the browser). If the viewer runs on your laptop, use the Jetson’s LAN address for rosbridge, or an SSH tunnel and override 127.0.0.1:PORT on that laptop.
